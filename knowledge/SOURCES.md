# SOURCES — registro único de fuentes del corpus RAG

Todas las fuentes fueron consultadas el **2026-10-11**. Cada documento de `knowledge/` y de
`backend/config/` cita estas fuentes como `[Knn]`.

**Regla de uso.**
- Lo que no tiene fuente se marca `⚠ sin fuente — heurística` (en YAML: `source: null  # ⚠ heurística provisoria`).
- **Tier `primary`**: universidad, gobierno, organismo profesional, artículo revisado por pares, o la propia empresa hablando de su proceso.
- **Tier `secondary`**: resumen de un tercero, repost o registro bibliográfico sin el texto completo.
- Columna **"Cómo se leyó"**: dice si se leyó el texto completo, solo el resumen o solo el registro bibliográfico. **No se afirma nada más allá de lo leído.**
