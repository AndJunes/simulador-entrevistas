# Backend Engineer (Python) — Nimbo Labs

> Aviso ficticio para probar la aplicación. Nimbo Labs no es una empresa real.

**Modalidad:** remoto (LATAM), solapamiento de 4 horas con la zona horaria de Nueva York.
**Contrato:** contractor, tiempo completo.

## Sobre Nimbo Labs

Somos una consultora de software de 60 personas que construye productos a medida para empresas de logística y salud.
Trabajamos en equipos chicos, con code review en todas las tareas y despliegues frecuentes.

## Qué vas a hacer

- Diseñar y mantener APIs REST en Python para los productos de nuestros clientes.
- Modelar datos en PostgreSQL y escribir migraciones seguras.
- Escribir tests automatizados y participar en code reviews.
- Colaborar con producto y frontend para definir contratos de API.
- Comunicar avances y bloqueos de forma proactiva.

## Requisitos

- 2 o más años de experiencia profesional con Python.
- APIs REST con FastAPI o un framework similar.
- SQL y PostgreSQL.
- ORM (SQLAlchemy o similar) y migraciones versionadas (Alembic o similar).
- Tests automatizados con pytest.
- Programación asíncrona en Python (asyncio, async/await).
- Control de versiones con Git y flujo de pull requests.
- Inglés oral y escrito para trabajar con clientes de Estados Unidos.

## Deseables

- Experiencia con LLMs: RAG, embeddings, búsqueda vectorial.
- Docker y algún proveedor cloud (AWS o GCP).
- Colas o workers para procesamiento en segundo plano.

## Proceso de selección

1. Entrevista con recruiting (30 minutos): trayectoria, motivación y logística.
2. Entrevista técnica (60 minutos): diseño de una API, SQL y preguntas sobre un proyecto propio.
3. Ejercicio práctico corto o live coding, a confirmar.
4. Charla final con el equipo.
