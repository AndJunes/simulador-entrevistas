# Full Stack Developer (React + Python) — Brisa Software

> Aviso ficticio para probar la aplicación. Brisa Software no es una empresa real.

**Modalidad:** remoto desde Argentina, Uruguay o Chile.
**Seniority:** semi senior.

## Qué buscamos

Una persona que pueda llevar funcionalidades de punta a punta en nuestra plataforma de reservas para gimnasios:
desde la base de datos hasta la interfaz.

## Requisitos

- 3 años de experiencia desarrollando aplicaciones web.
- React con TypeScript.
- Backend en Python (Django o FastAPI).
- PostgreSQL y diseño de modelos de datos.
- Tests en frontend y backend.
- Accesibilidad web (WCAG) y diseño responsive.
- Comunicación clara con clientes y con el equipo.

## Deseables

- Experiencia con pagos online.
- CI/CD con GitHub Actions.
- Inglés técnico.

## Proceso

1. Entrevista inicial con People (30 minutos).
2. Entrevista técnica: revisión de código y diseño de una funcionalidad (60 minutos).
3. Entrevista con un cliente simulado: cómo explicás decisiones técnicas a alguien no técnico.
